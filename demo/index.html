Beautiful falling autumn leaves for any website. Zero dependencies, fits every screen.

// npm install @autumnboy-studio/seasons
import { autumn } from '@autumnboy-studio/seasons'

autumn.render()
<!-- or, without npm -->
<script src="https://cdn.jsdelivr.net/npm/@autumnboy-studio/seasons"></script>
<script>Seasons.autumn.render()</script>

Why it's nice

  • Adapts to any screen: phones get fewer leaves, big screens more, and it follows resizing and rotation.
  • Never blocks clicks, and is hidden from screen readers.
  • Pauses when the tab is hidden, and respects "reduce motion".
  • Tiny, with zero dependencies and no tracking.
