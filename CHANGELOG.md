# Changelog

All notable changes to this project are documented here.
This project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-07

### Added
- `autumn.render()` with falling maple and oval leaves, colour gradients, veins, tumbling and soft shadows.
- Responsive overlay: leaf count and size adapt to the screen; follows resizing, rotation and pixel density.
- `pause()`, `resume()`, `stop()` and `isRunning`.
- Options: `count`, `speed`, `size`, `wind`, `colors`, `opacity`, `container`, `zIndex`, `maxPixelRatio`, `reducedMotion`, `pauseWhenHidden`, `seed`.
- Pauses in hidden tabs and respects `prefers-reduced-motion` by default.
- Script-tag build (`window.Seasons`) and TypeScript types.
- `npx @autumnboy-studio/seasons` terminal greeting.
